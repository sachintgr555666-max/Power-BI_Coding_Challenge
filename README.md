# Employee Details & Performance Dashboard

## 📊 Project Overview

This project is an Employee Details and Performance Dashboard created using Power BI.

The main purpose of this dashboard is to analyze employee information, salary, department distribution, performance ratings, country-wise salary, and employee trends.

I created this dashboard to practice data analysis, data visualization, and dashboard development using Power BI.

---

## 🎯 Objectives

- Analyze the total number of employees
- Understand employee distribution across departments
- Analyze average and total salary
- Compare salary across different countries
- Analyze employee performance ratings
- Understand employee count trends over the years
- Compare performance with the given target
- Explore employee details using filters

---

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

## 🔄 Data Preparation

The data was prepared and transformed using Power Query.

The main steps included:

1. Loading the employee dataset into Power BI
2. Checking the data types
3. Handling missing or unknown values
4. Cleaning and transforming the data
5. Creating required calculations
6. Building relationships where required
7. Creating DAX measures
8. Designing interactive dashboards

---

## 📊 DAX Measures

Some of the measures used in this project include calculations for:

- Total Employees
- Average Salary
- Total Salary
- Average Performance Rating
- Target Performance

These measures were used to create KPI cards and dashboard visuals.
